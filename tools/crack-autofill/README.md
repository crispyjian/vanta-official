# VANTA × CRACK Story Autofill

VANTA 5명(서이현·백시온·차도겸·유태경·한서율)의 크랙 스토리 **등록 화면을 단계별로 자동입력**하는 크롬 데스크톱 확장 프로그램입니다.

## 설치 (PC Chrome / Edge)

1. 이 폴더를 ZIP으로 내려받았다면 압축을 해제합니다.
2. 크롬 주소창에서 `chrome://extensions` (Edge: `edge://extensions`)를 열고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** → `manifest.json`이 들어 있는 `vanta-crack-autofill` 폴더를 선택합니다.
4. [크랙](https://crack.wrtn.ai/)에 직접 로그인하고 **스토리 만들기**에 들어갑니다.
5. 툴바의 **VANTA · 크랙 스토리 자동입력**을 열어 멤버와 현재 단계를 고른 다음 **현재 단계 자동입력**을 누릅니다.
6. 등록 화면에서 자동입력 결과를 확인하고 **다음 단계로 직접 이동**합니다. 다음 단계에서도 5번을 반복합니다. **최종 게시·공개는 직접** 합니다.

> 이 도구는 `프로필 설정`(이름·한 줄 소개), `스토리 설정`(스토리 설정 및 정보), `시작 설정`(프롤로그·시작 설정 이름·시작 상황·플레이 가이드)에서 **레이블을 찾은 항목만** 채웁니다. 사이트 실제 구조 변경, 커스텀 리치텍스트 입력창, 이미지 업로드는 완전 자동으로 보장되지 않습니다. 인식하지 못한 입력칸은 건너뛰고 확장 프로그램에 표시합니다. 사용자의 계정 비밀번호/쿠키는 수집하거나 서버로 전송하지 않습니다.

## 내용 수정

확장 프로그램을 열면 입력될 내용이 미리 보입니다. 직접 바꿔 쓰면 브라우저의 `chrome.storage.local`에 저장됩니다. 처음 상태로 되돌리려면 확장 프로그램의 데이터를 초기화하거나 재설치하세요.

`stories.json`은 최초 기본 초안이며, 이 파일을 수정하고 확장 프로그램을 새로고침한 후 *브라우저에 저장된 기존 수정 내용이 없다면* 수정본이 반영됩니다. 멤버 이름·설정은 기존 [VANTA 공식 홈페이지](https://crispyjian.github.io/vanta-official/)와 [UNIVERSE](https://crispyjian.github.io/vanta-official/universe.html)의 공개 설정을 토대로 했습니다. 작성한 시작 장면은 **새로 구성한 초안**이므로 게시 전에 직접 검토하세요.

## 제약과 보안

- **GitHub Pages 페이지 자체는 다른 도메인인 크랙의 입력칸을 자동 조작할 수 없습니다.** 크롬 확장 프로그램이 브라우저에서 현재 크랙 탭에 주입되어야 합니다.
- **iPhone의 일반 Safari·Chrome에서는 이 데스크톱 Chrome/Edge 확장 프로그램을 바로 사용할 수 없습니다.** PC에서 사용하세요.
- 로그인 인증, 그림 업로드, 모델 선택, 스탯/키워드북/엔딩 등 기타 선택 기능, 최종 게시 버튼은 직접 확인하고 진행해야 합니다.
- 이 확장 프로그램은 크랙 공식 제공 기능이나 크랙 운영사의 승인을 받은 통합 도구가 아닙니다. 실제 입력 테스트 전의 시제품이며 UI 변경 시 조정이 필요합니다.
- 확장 프로그램은 크랙 도메인에서 실행하고 Chrome 로컬 저장소만 사용합니다. 비밀번호, 로그인 토큰, 외부 API 키는 코드에 보관하지 않습니다.

## 구성

- `manifest.json`: 크롬 확장 프로그램 설정
- `popup.html`: 멤버·단계·입력값 확인 화면
- `popup.js`: 단계별 필드 탐색 및 입력 이벤트
- `stories.json`: VANTA 5명 이야기 초안

서로 다른 멤버의 스토리를 만들 때는 크랙에서 **새 스토리 만들기**를 다시 열고 멤버를 바꿔 진행하세요.
